# Доска объявлений

Фронтенд для учебного задания.

## Реализовано

- GET https://inai-col1.fishrungames.com/ads — получение списка объявлений.
- POST https://inai-col1.fishrungames.com/ads — добавление объявления.
- Поля: title, description, price, image.
- Отображение изображений.
- Адаптивный интерфейс.

## Запуск

Откройте `index.html` в браузере.

Если браузер блокирует запросы при открытии файла напрямую, запустите папку через любой локальный сервер (например, Live Server в VS Code).
